# Technology Stack

**Analysis Date:** 2026-07-11

## Languages

**Primary:**
- HTML5 - Structure and semantics of the main landing page (`index.html`)
- CSS3 - Design, themes (light/dark), layout, responsive styling, and custom animations (`style.css`)
- JavaScript (ES6) - Animations, theme toggle, menu behavior, sound management, and DOM manipulation (`main.js`)

## Runtime

**Environment:**
- Browser - Runs entirely client-side in the user's web browser.

**Package Manager:**
- None - Static web assets loaded directly without package management tools.

## Frameworks

**Core:**
- None - Vanilla HTML/CSS/JS application.

## Key Dependencies

**Critical:**
- AOS (Animate on Scroll) Library v2.x - CSS library (`unpkg.com/aos@next/dist/aos.css`) and JavaScript library (`unpkg.com/aos@next/dist/aos.js`) for scroll animations.
- BuyMeACoffee Widget v1.0.0 - External donation widget script (`cdnjs.buymeacoffee.com/1.0.0/widget.prod.min.js`).

**Infrastructure:**
- Google Fonts API - Custom typography (Passions Conflict, Orbitron, Fira Code, Six Caps) loaded via `fonts.googleapis.com`.
- Google Analytics gtag.js - Analytics and page tracking (`G-YMWDE0VTD3`).

## Configuration

**Environment:**
- Fully client-side. No server-side environment variables or configuration files.

**Build:**
- None.

## Platform Requirements

**Development:**
- Any platform with a text editor and a standard web browser.

**Production:**
- Hosted on GitHub Pages (static site hosting).
